# Результаты AppSec-проверок

Проверки выполняются в изолированной учебной среде. Результаты сканеров
требуют ручной оценки и не являются доказательством отсутствия уязвимостей.

## SAST — Semgrep

Дата последнего разбора: 2026-11-12.

Команда локальной проверки:

```powershell
semgrep scan --config p/owasp-top-ten --config p/nodejs backend frontend
```

### `dockerfile.security.missing-user`

**Статус:** подтверждённое замечание по наименьшим привилегиям.

**Файлы:** `backend/Dockerfile`, `frontend/Dockerfile`.

В Dockerfile не задан непривилегированный пользователь. Образ `node:20-alpine`
по умолчанию запускает процесс от `root`; это может увеличить последствия
компрометации приложения внутри контейнера, но само по себе не означает
получение root-доступа на хосте.

### `javascript.express.session-fixation`

**Статус:** вероятное ложное срабатывание для текущего кодового потока.

В обработчике входа cookie получает JWT, который сервер подписывает через
`jwt.sign` после успешной проверки пароля. Значение cookie не копируется из
переданного клиентом cookie или другого значения сессии из запроса.

### `javascript.express.web.cookies-secure-false-express`

**Статус:** контекстный риск локального HTTP-сценария.

При `secure: false` браузер может отправлять cookie по HTTP. `httpOnly` не
защищает от перехвата сетевого трафика.

## SCA — Dependabot

Dependabot еженедельно проверяет npm-зависимости frontend/backend и версии
GitHub Actions. Уведомления и pull request нужно оценивать по затронутому
пакету, доступной исправленной версии и влиянию обновления; отсутствие PR не
является заключением об отсутствии риска.

## DAST — OWASP ZAP Baseline

Сканирование направлено на frontend dev-сервер (`http://localhost:5173`).
Оно не покрывает аутентифицированные API-маршруты.

В проверенном отчёте ZAP отметил:

- `10038 Content Security Policy (CSP) Header Not Set` — 3 ответа: `/`,
  `/robots.txt` и `/sitemap.xml`;
- `10020 Missing Anti-clickjacking Header` — ответ на `/sitemap.xml`.

Это находки об отсутствующих заголовках, а не подтверждение успешной атаки.
Указание URL `/robots.txt` или `/sitemap.xml` означает, что сканер запросил
эти пути; оно не доказывает наличие файлов. Полный HTML-отчёт доступен как
artifact соответствующего запуска GitHub Actions.
